# BMAD Method — installed

This repo has [BMAD Method](https://bmadcode.com/) (Breakthrough Method for Agile AI-Driven Development) installed for Claude Code.

## What got added
- `.claude/skills/` — 49 BMAD skills registered for Claude Code
- `_bmad/` — BMAD core module, config, and agent definitions
- `_bmad-output/` — where BMAD writes generated PRDs, architecture docs, and story files as you use it

## How to use it
1. Clone/pull this repo locally.
2. Open the project folder in **Claude Code** (`claude` in your terminal, inside this directory).
3. Ask Claude "what is the bmad-help skill" or just describe what you want to build — Claude Code will pick up the BMAD skills automatically.
4. Typical flow: **Analyst** (clarify the idea) → **PM** (write a PRD) → **Architect** (design it) → **Scrum Master** (break into stories) → **Dev** (implement) → **QA** (test).

## Updating BMAD later
From the project root:
```bash
npx bmad-method install --directory . --tools claude-code --action update
```
